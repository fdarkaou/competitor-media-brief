Competitor media brief

Do your rivals send their Meta and TikTok ad clicks to the App Store, or to a web page first? Paste one or more PeekPanda media responses and this page shows each app's destination split, its landing pages, its live ads and the public organic posts that mention it. Nothing leaves your browser; this page never calls the API.

Optional: paste a report you saved earlier (CLI --format json or a --state file) to see what changed since then.

Where to get the JSON

The input comes from PeekPanda, an iOS competitor catalogue where every app has a case file of dated, stored evidence. Read one app's media view with an API key (one call from your plan's daily API and MCP allowance):

curl --get 'https://api.peekpanda.com/v1/competitors/ios/1000000001/media' \
  --header "Authorization: Bearer $PEEKPANDA_TOKEN" \
  --header 'x-genviral-tenancy: personal'

Paste a single response, or a JSON array of them. Over MCP the same read is get_app with action media. The get competitor media reference lists the fields. The command-line version on GitHub reads several apps for you, follows the live ads list across pages, keeps a weekly diff and can post to Slack or Discord.

Destination counts are where the app's stored ads sent their clicks; only App Store ads count as App Store. The live ads list is newest discovered first and about a minute behind new ads. Organic matches are suggestions, not verified ownership. Zero stored ads is not proof of none anywhere. There is no spend or reach here. Image and video links are short-lived, so this page does not show them.
